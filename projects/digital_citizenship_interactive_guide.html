Instructional Design Case Study

Project Overview

Converting Static Print Content to Interactive Microlearning

This interactive module transforms dense static flyer text into a touch-friendly microlearning application. By chunking information into discrete 3D cards, learners engage in self-paced exploration and active recall.

Audience

Higher education students, K-12 teachers, and onboarding employees.

ID Objective

Maximize visual impact, eliminate cluttered whitespace, and support retrieval practice.

Key Design Decisions

1. High-Impact Full-Bleed Fronts

Replaced dull boxes with edge-to-edge color gradients and 9xl vector icons for instantaneous visual recognition of each domain.

2. Elimination of Visual Noise

Removed redundant prompt text ("click to reveal") in favor of intuitive physical interaction affordances.

3. Precise 3D Layout Stacking

Utilized strict CSS absolute positioning (`inset: 0`) and 3D backface isolation to guarantee seamless in-place card rotation.
